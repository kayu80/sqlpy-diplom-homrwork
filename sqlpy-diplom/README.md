

### Инструкция по работе с ботом

Программф-бота выполняет следующие действия.
1. Заполнена база данных общим набором слов для всех пользователей (цвета, местоимения и т.д.). 
2. Программа предлагает 4 варианта ответа на английском языке в виде кнопок.
3. При правильном ответе подтверждает ответ, при неправильном - предлагает попробовать снова.
4. Реализована функция добавления нового слова.
5. Реализована функция удаления слова. Удаление реальзовано персонально для пользователя.
6. Новые слова не появляться у других пользователей.
7. Работа с ботом после запуска начинается с приветственного сообщения. 
<details>
  <summary>Вот сообщение с которого начинается запуск</summary>
  
  Привет 👋
  Давай попрактикуемся в английском языке. Тренировки можешь проходить в удобном для себя темпе. 

  У тебя есть возможность использовать тренажёр, как конструктор, и собирать свою собственную базу для обучения. Для этого воспрользуйся инструментами:
  - добавить слово ➕,
  - удалить слово 🔙.

  Ну что, начнём ⬇️
</details>
