# EnglishCard — Telegram-бот для изучения английского языка

Курсовая работа по курсу «Базы данных».

## Описание

Бот помогает изучать английский язык через карточки: пользователю
показывается русское слово, и нужно выбрать правильный английский
перевод из кнопок. Каждый пользователь может добавлять свои слова
и удалять их. Общий словарь доступен всем.

## Схема базы данных

| Таблица       | Описание                                              |
|---------------|-------------------------------------------------------|
| `users`       | Зарегистрированные пользователи бота                  |
| `dictionary`  | Общий словарь (стартовые слова для всех пользователей)|
| `user_words`  | Персональные слова, добавленные пользователем         |

Связь: `users (1) → user_words (N)` через `user_id`.

## Установка и запуск

### 1. Создание БД

```sql
CREATE DATABASE englishcard_db;
```

### 2. Настройка подключения

Откройте `db.py` и измените `DB_CONFIG`:

```python
DB_CONFIG = {
    "dbname": "englishcard_db",
    "user": "postgres",
    "password": "ВАШ_ПАРОЛЬ",
    "host": "localhost",
    "port": 5432,
}
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Токен бота

Получите токен у [@BotFather](https://t.me/BotFather)
и вставьте его в `main.py`:

```python
TOKEN = "ВАШ_ТОКЕН"
```

### 5. Запуск

```bash
python main.py
```

В Telegram отправьте боту команду `/start`.

## Функционал

- **Карточки**: бот показывает русское слово, пользователь выбирает
  английский перевод из 4 кнопок.
- **Добавление слова**: кнопка «Добавить слово ➕», затем ввод в формате
  `Apple | Яблоко`. Слово сохраняется персонально для пользователя.
- **Удаление слова**: кнопка «Удалить слово 🔙» — удаляет текущее
  персональное слово.
- **Подсчёт слов**: после добавления бот сообщает, сколько персональных
  слов у пользователя.
